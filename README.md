# SophiaGroom.github.io

Portfolio site for Sophia Groom — Computer Science student at Duke & Duke Kunshan University.

## Pages

- `index.html` — home / hero
- `projects.html` — selected technical projects
- `aboutme.html` — reserved for personal writing
- `resume.html` — viewable resume (PDF embed + HTML)
- `contact.html` — Duke email, LinkedIn, resume links
- `Sophia_Groom_Resume.pdf` — downloadable tech resume

## Local preview

```bash
python3 -m http.server 8000
```

Visit `http://localhost:8000`.

If the live site looks outdated after a merge, hard-refresh the browser (`Cmd+Shift+R` / `Ctrl+Shift+R`) — GitHub Pages can cache CSS briefly.
